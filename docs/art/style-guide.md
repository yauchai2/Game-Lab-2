# 美術風格指南

來源：參考影片《Ice Cream》（約 3:12）與《SLUMLORDZ SANDWICH》（約 1:56），兩條均為 960×720、24fps，加上角色設定稿第四節。

## 影片觀察

**世界與場景**
- 日系與亞洲都市街區：高架鐵路、電線、招牌、便利店、自動販賣機、小貨車、欄杆。
- 場景是低多邊形大面積造型，配手繪感貼圖與少量像素化招牌與塗鴉。
- 植物用方塊狀、圓團狀葉叢，不追求寫實。

**角色**
- 長腿、窄上身、寬褲、厚底大鞋；頭小，五官用像素或簡化貼圖。
- 髮型是幾塊大面體的尖刺或斜片，辨識度高。
- 平塗、霧面，沒有真實布紋或金屬反射。

**色彩與光**
- 日間：高飽和藍天、白雲、嫩綠、粉紅、黃色車身，整體明亮、乾淨。
- 室內與夜戲：偏暗，用黃色百葉窗光與紫、綠霓虹作對比，仍以平塗為主。
- 陰影大塊、柔邊，不用複雜光照。

**鏡頭與動態**
- 大量低角度仰拍、廣角魚眼、貼地鏡頭（拍鞋、腿、褲腳）。
- 突然的特寫（臉、手、物件），再切到大景。
- 動作戲用速度線、旋轉鏡頭、誇張透視；日常戲則放慢，重心歪斜、晃動鞋尖。
- 畫面有少量復古（低解析、像素）感，與現代 3D 混合。

## 可直接使用的風格規則（對應角色設定稿）

1. 極低多邊形、少量大面，但模型要有完整厚度（不是紙片）。
2. 霧面平塗貼圖；五官用像素貼圖，表情可更換。
3. 比例約 6 至 6.5 頭身；四人有身高差（Jax 174 > Niko 168 > Vee 166 > Skye 162，見 `characters.md`）。
4. 去色後仍分得出四人：靠帽子與髮型、褲型、鞋型、配件、站姿。
5. 避免：寫實布紋、金屬反射、密集零件、遮住五官的常駐特效。
6. 鏡頭語言：低角度、廣角、貼地，作為標誌性演出。

## 技術建議（零基礎友好）

- 遊戲內使用「低解析渲染加放大」，自然得到階梯輪廓（Godot 可設定低解析 SubViewport）。
- 貼圖尺寸小（例如 64 至 128px），使用最近鄰過濾（Nearest），保留像素感。
- 單一角色面數目標：約 1,500 至 3,000 個三角面。

## 2026-10-30 新增：國際化混搭（攻殼與 Cyberpunk 氛圍）

- 不要港式元素；城市名為「疊域」。整體走國際化與日系：高架、便利店、自動販賣機、立食店。
- 垂直分層：上層企業塔（冷白、發光）、下層潮濕舊區（暗、雜亂）、中間亂接的管線、纜線與招牌。
- 招牌混用漢字、假名、拉丁字母與虛構符號，不屬於任何一個國家。招牌上的中文一律使用書面語，不使用港式用字，也不使用粵語口語。
- 色調：深藍紫色底配霓虹（洋紅、青、橙）；仍然平塗、霧面。
- 只取氛圍，不照搬標誌性元素（義體廣告、和風霓虹雨夜的固定組合），避免被指抄襲。
