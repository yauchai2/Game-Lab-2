# 企劃草案

狀態：草案，等 Alan 回答「待決定問題」後定稿。

## 已決定

- **類型／視角：** 類 Path of Exile 2 嘅動作 RPG，斜俯視 3D 鏡頭，滑鼠點擊移動 + 技能鍵。
- **角色：** 玩家揀一個角色玩（Jax／Vee／Skye／Niko，四個職業各有玩法），單人。
- **平台：** PC 為主，設計時預留 Web 試玩版同手機版（見下）。

## 平台策略

Godot 4 同一個專案可以匯出 PC、Web、Android／iOS，所以「一份遊戲多平台」做得到，但唔建議一開始三個一齊做。

| 平台 | 可行性 | 要注意 |
|---|---|---|
| PC | 最順，主力開發同測試 | 滑鼠 + 鍵盤技能 |
| Web | 可以，適合出試玩版 | 載入慢、檔案要細、部分功能受限；低多邊形 + 細貼圖正好合適 |
| 手機 | 可以，但要另外設計操作 | 無滑鼠，要觸控搖桿／技能按鈕；畫面細，介面要放大；RPG 背包、技能樹要簡化 |

**建議：** PC 先做；由第一日就用「可縮放介面」、細貼圖、低面數，等 Web 試玩版容易出；手機版等 PC 玩法穩定後再加觸控操作。

## 零基礎工具路線（建議）

| 階段 | 做咩 | 工具 |
|---|---|---|
| 0 | 睇住 Godot 內建方塊/膠囊做灰盒，玩法先行 | Godot 4 |
| 1 | 用 Godot 讀入簡單角色，行路、跳、鏡頭 | Godot 4（GDScript） |
| 2 | 用 Blender 做 1 個低多邊形角色（Jax 先） | Blender 最小路線：方塊建模 → 貼色 → 簡單骨架 |
| 3 | 逐個加角色、街景、動畫 | 同上 |

**最小學習路徑：** Blender 只學「方塊建模、擠出、頂點上色、匯出 glb」；Godot 只學「場景、角色移動、鏡頭、匯入模型」。我會逐步寫好腳本同步驟俾你照做，你唔需要一次學晒。
