# 企劃草案

狀態：草案，等 Alan 回答「待決定問題」後定稿。

## 待決定問題

1. **玩法類型：** 動作冒險（四人切換）／街頭解謎探索／輕量戰鬥？
2. **視角：** 第三人稱 3D（最貼近參考影片）／固定鏡頭／橫向？
3. **人數：** 單人切換四個角色，定係本地多人？
4. **平台：** PC 為先？之後會唔會出手機／網頁？
5. **規模：** 先做一個「街角小關卡 + 一個角色可郁」嘅試玩版，OK 嗎？

## 零基礎工具路線（建議）

| 階段 | 做咩 | 工具 |
|---|---|---|
| 0 | 睇住 Godot 內建方塊/膠囊做灰盒，玩法先行 | Godot 4 |
| 1 | 用 Godot 讀入簡單角色，行路、跳、鏡頭 | Godot 4（GDScript） |
| 2 | 用 Blender 做 1 個低多邊形角色（Jax 先） | Blender 最小路線：方塊建模 → 貼色 → 簡單骨架 |
| 3 | 逐個加角色、街景、動畫 | 同上 |

**最小學習路徑：** Blender 只學「方塊建模、擠出、頂點上色、匯出 glb」；Godot 只學「場景、角色移動、鏡頭、匯入模型」。我會逐步寫好腳本同步驟俾你照做，你唔需要一次學晒。
