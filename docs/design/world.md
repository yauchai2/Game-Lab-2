狀態：**Alan 已確認五個方向（2026-10-30）**，細節仍可改。大致沿用舊版 Game-Lab 嘅世界設定（`world-current.md`、`story.md`、`creative-direction.md`），按今次「類 Path of Exile 2 動作 RPG、揀一個角色玩」改寫；同舊版唔同嘅位標記為「【改】」，詳見文末。人物個別背景、口吻、成長見 `characters.md`。

## 一、一句講晒

**疊港係一座一直加建、從來唔收工嘅城市。居民將過時嘅工具改成自己嘅生活；四個少年少女帶住各自嘅壞習慣上街，想為自己掙一點選擇，結果每個選擇都有後果。**

玩家唔係救世主，係有啲本事、仲喺度摸索嘅街頭少年少女。自由唔係推翻全城，而係保住自己嘅工作角落、搵到另一條路、決定點用自己啲嘢。

## 二、城市：疊港

- 舊碼頭、倉區、住宅同高架物流平台一層層加建喺一齊：新路跨過舊天台，停用貨台變球場，高架下面有洗衣店、早餐檔同改裝攤。唔係上面壞、下面好，或者相反。
- 日間：曬褪嘅橙牆、冷藍天、白色貨車；夜晚：暖黃小店、紫藍天色、仲亮住嘅自助機。有海風、空地、懶坐嘅台階，亦有趕工、失約同危險。
- 年代：日常街頭質感（街機、二手電器、影印傳單）混少量冷調電子（耳罩介面、控制器、巡檢設備）。確切年代、人口唔交代。
- 視覺沿用 `style-guide.md`：極低多邊形、霧面平塗、低角度廣角鏡頭。

## 三、五條運作規則（城市點解咁荒謬）

| 規則 | 日常可見嘅結果 |
|---|---|
| 設備耐用，規格淘汰得快 | 部貨車仲行得，但接口停用入唔到新倉；街坊照樣改作別用 |
| 基建共用，使用權分散 | 一道門涉及屋主、承包商同公共通道，大家互相推責 |
| 卡匣存方法，實體件負責做事 | 技能「模式」可以抄傳，但穩定輸出仍要啱嘅核心同配件 |
| 自動化做重複工作，人決定用途 | 機器可以巡線，但邊個嘅貨可以攞走仍要人負責 |
| 街區資訊有差異，亦可互通 | 回收攤熟庫存，跑線仔知入口，維修員知邊個接點危險 |

## 四、勢力（敘事組織，唔係陣營系統）

| 稱呼 | 想保住咩 | 有用同麻煩之處 |
|---|---|---|
| **聯務署** | 共用道路、供電同設備責任追得返 | 有人認真維護安全，有部門只求流程完結（封路告示、檢修記錄） |
| **整件回收** | 低成本集中回收、控制零件轉售渠道 | 處理得危險廢件，亦會將仲可用嘅嘢成批劃走（取消單、自動清場設備） |
| **散檔** | 各自嘅小生意、能用嘅設備同交換門路 | 攤主同工作間嘅俗稱，無統一領袖；互相幫忙亦會爭客、食言 |
| **清場組（黑衣人）** | 替整件回收外判「清場」：追回卡匣、收走設備、堵住走漏嘅貨 | 主要戰鬥敵人；底層係打工仔，上層係專業殺手；有槍、有車（見第九節） |

壞人唔靠制服、全黑配色或長篇宣言建立；清場組嘅個性來自佢哋做嘢嘅方式（見第九節）。威脅可以係逐利嘅人、私改測試、錯誤部署嘅設備或怪異改裝體；普通路人只係旁觀、避開或繼續生活。

## 五、核心衝突與故事骨架

主題：**邊個有權決定工具點用、路畀邊個行、被淘汰嘅嘢仲有冇價值。** 唔係「打倒大魔王」。

開場（沿用舊版）：玩家接一張**取消得太遲嘅回收單**，喺一間清倉店拎走一批舊設備，箱入面有張冇型號嘅**模式卡匣**。整件回收取消委託，清運員 Ren 上門要回整箱嘢；自動回收設備連店家仲用緊嘅貨都算埋。玩家清路、核對邊啲屬店家、搵收貨編號，由此引出追查高架倉線上流通嘅模式。

| 章 | 玩家嘅目的 | 揭露 |
|---|---|---|
| 1 橋底里 | 搵收貨人、脫身 | 第一次模式改變 |
| 2 散貨窗口 | 搵人鑑定同改裝 | 不同改裝流派 |
| 3 倉樓（被改成工作角落） | 進入受勢力控制嘅舊樓 | 委託開始有取捨 |
| 4 高架繞路 | 繞過封鎖、跨區 | 場景放大、進階模式；車追逐只做演出 |
| 5 停產測試場 | 追查模式點解被封存 | 第一段主線收束 |
| 6 港務口 | 保住流通路線 | 留低可繼續探索嘅出口 |

第 2–6 章只係方向，等第 1 章玩法驗證後再細化。

## 七、黑色幽默同氣氛規則

- **荒誕但後果係真**：畫面唔寫實暴力；少量暴力、反叛等成熟題材可有，但四人係 16／17 歲，重點係友情、自由、逞強、失誤同成長。
- **官僚幽默，結果留喺畫面**：例如設備攔住有收據嘅貨，旁邊打印機照印「提高流通效率」。NPC 唔解釋笑位。
- **鬆弛同突然爆發對比**：空台場有人慢慢食午飯，下一個路口設備突然郁。亮色街景都有風險，冷色倉區都有人幫手。
- **唔係每個任務都係陰謀**：可有錯送波鞋、荒唐但有效嘅接法等小事。
- 少用「修復一切」「每個人都被聽見」嘅暖心總結。

## 九、黑衣人、槍械、車追逐、打碟（Alan 新點子，草案）

靈感來自 SLUMLORDZ ~ SANDWICH 嘅氣質（一群黑衣人、槍、車追逐、打碟）。只借氣質，唔抄影片入面嘅人物、組織或橋段。

### 1. 黑衣人＝「清場組」（偏殺手路線，Alan 提出）
- **係咩：** 整件回收外判嘅清場隊，開場追返卡匣嗰班人。分兩層：
  - **底層（打工仔）：** 編號牌小兵、持槍手、駕駛。有禮貌、按單做嘢，講「收到，已記錄」，打低會掉工作證同飯盒。
  - **上層（殺手）：** 組長同每章頭目。安靜、專業、少話，接「合約」做嘢；黑色幽默來自合約文化（「取消費另計」「完成率 97%」「今日第三張單」）。佢哋先係真正危險、令人有壓迫感嘅對手。
- **識別（唔淨係全黑）：** 黑西裝、工作證、耳掛對講機、臂上編號牌（越細越高級）；殺手各有一個招牌道具或習慣（例如永遠帶傘、只用一種槍、做嘢前先擦眼鏡），畀玩家記得住。
- **偏殺手嘅限度：** 氣氛可以更冷、更緊張，但仍然係荒誕黑色幽默；暴力風格化（見 2），唔寫實血腥，唔寫處決場面。玩家角色係 16／17 歲，故事上係「被合約盯上」，重點係逃、反擊同後果，唔係殺戮。
- **立場唔單一：** 有打工仔私下放生玩家；有殺手對合約有自己嘅底線，可成為後期關係線。
- **同四人嘅關係：**
  - Jax：打爆佢哋架車同閘門，最易令「得罪殺手」變成「街坊被針對」。
  - Vee：干涉對講機同瞄準器，令槍手互相認錯人。
  - Skye：槍械迷，睇得出殺手用咩槍；玩弄巡邏編號同打卡時間。
  - Niko：對裝甲貨車、起重車流口水，想搶嚟控制。

### 2. 槍械（Alan 已確認）
- **難度：低至中。** 槍手就係「遠程敵人」：持槍姿勢 → 瞄準線／短停頓（預警）→ 發射彈丸 → 玩家閃避。現有原型已有追擊敵人，加彈丸同預警即可。
- **畫面處理：** 子彈係粗身色條；中彈係打飛、掉帽、公文紙屑爆開，**唔寫實血腥**，貫徹「荒誕而後果真」。後果落喺故事（街坊受影響、回收單、關係），唔落喺血。
- **玩家角色用槍：** Skye 係槍械角色（武器輪替係佢嘅玩法特色）；其餘三人唔靠槍，避免四人撞玩法。

### 4. 打碟（Alan 已確認：先場景＋DJ 頭目戰）
- **場景（低難度）：** 散檔嘅音樂攤、地下夜場。做 hub 或安全區，玩家聽 DJ 播歌、換歌，同時係街區生活感。
- **頭目戰（中難度）：** DJ 頭目，每首歌＝一個階段：節拍決定彈丸節奏／地板區域，玩家要跟節拍閃避。唔使真正嘅節奏遊戲判定。

## 十一、酷感準則：深層次嘅型（Alan 要求，對標 SLUMLORDZ ~ SANDWICH）

型唔係靠黑衣、霓虹、槍，而係靠態度同選擇。承接舊版創作基準（深層反叛、打破常規、懶散鬆弛、黑色幽默、自由、對比）。

1. **從容過人**：角色喺危險前反而慢、靜、少話（Vee 停手確認、Niko 低聲一句、Skye 懶懶晃鞋尖）；爆發要突然，先有鬆弛先有對比。
2. **反叛有理由**：唔係為反而反。每個人嘅「打碎、覆寫、打亂、支配」都來自個人慾望，同「點解條規矩值得質疑」掛鈎。
3. **日常同危險並存**：吃飯、發呆、玩滑板、聽歌之間突然出事，之後又繼續生活。
4. **幽默冷面，唔解釋**：笑位放喺畫面（例如打印機照印「提高流通效率」），NPC 唔講「你睇多荒謬」。
5. **對白克制**：短句、留白，唔講大道理、唔做反叛宣言。
6. **後果令型有重量**：酷嘅動作之後有代價（街坊、關係、退路），唔係無代價嘅爽。
7. **鏡頭同美術幫手**：低角度、廣角、突然特寫、速度線；日間高飽和、夜間黃光配紫綠霓虹；平塗唔寫實。
