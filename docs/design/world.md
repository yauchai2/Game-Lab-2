# 世界觀

狀態：草案，方向已由 Alan 確認（2026-10-30），細節仍可修改。城市名為「疊域」；基調為「日常但反社會」，並保留黑色幽默與溫情，整體感覺對標《SLUMLORDZ SANDWICH》；美術走國際化與日系，混搭攻殼機動隊與 Cyberpunk 氛圍。大致沿用舊版 Game-Lab 的疊域設定（`world-current.md`、`story.md`、`creative-direction.md`），按「類 Path of Exile 2 動作 RPG、開局選一名角色」改寫，差異見第十二節。人物背景、口吻、成長見 `characters.md`；玩法與平台見 `game-plan.md`。

全部文檔與遊戲內文字一律使用書面語，不使用粵語或港式用字。

## 一、一句話概括

**疊域沒有人規劃，只有人亂建；高架下是店舖，屋頂上是住宅，便利店永遠亮著燈。四個少年少女不信規矩、只信自己的手，逃單、翻閘、把報廢機器改成裝備；每次鑽空子，都有人來收數。**

玩家不是救世主，是不守規矩的街頭少年少女。自由不是推翻全城，而是不被體制收編、守住自己的角落、用自己的方法過日子。

## 二、酷感準則：深層次的型（對標 SLUMLORDZ SANDWICH）

型不靠為酷而酷，而靠態度與選擇。美術可以用霓虹，但不能只靠霓虹。之後所有角色、敵人、劇情都按這十條檢查。

1. **從容過人**：危險面前反而慢、靜、少話（Vee 停手確認、Niko 低聲一句、Skye 懶懶晃著鞋尖）；爆發要突然，先有鬆弛才有對比。
2. **反叛有理由**：每個人的「打碎、覆寫、打亂、支配」都來自個人慾望，並與「為何這條規矩值得質疑」掛鉤。
3. **日常與危險並存**：吃飯、發呆、玩滑板、聽歌之間突然出事，之後又繼續生活。
4. **幽默冷面，不解釋**：笑點放在畫面裡（例如打印機照常印出「提高流通效率」），NPC 不會說「你看多荒謬」。
5. **主角幾乎不說話，以動作表達**：四位主角不說台詞，只有極少量單字、笑聲、氣聲等短音；情緒與態度靠動作、表情、姿勢、音效與標誌性小動作。文字與對白主要由 NPC、告示與機器廣播承擔，不講大道理，不做反叛宣言。
6. **酷的動作有代價**：街坊、關係、退路，不是無代價的爽快。
7. **鏡頭與美術幫忙**：低角度、廣角、突然特寫、速度線；日間高飽和，夜間黃光配紫綠霓虹；平塗，不寫實。
8. **不做**：全員陰沉殺手、無差別傷害路人、純為酷而酷的黑衣霓虹、角色自己說「我很酷」。
9. **粗俗但不是直白粗口**：NPC 可以講粗俗語言與狠話，靠市井口氣、荒誕比喻、嘲諷與停頓，不靠髒字；主角的粗俗與狠勁以動作表達。細則見第九節。
10. **反社會的對象是體制**：主角反的是規矩、收數的大人物、管理方；偶爾要有細小代價（例如逃單令小店虧一點），但不做無差別害人。

## 三、城市：疊域

- 舊碼頭、倉區、住宅與高架物流平台一層層加建在一起：新路跨過舊天台，停用貨台變成球場，高架下面有便利店、立食店、自動販賣機和改裝攤。不是上面壞、下面好，也不是相反。
- 日間：曬褪的橙牆、冷藍天、白色貨車；夜晚：暖黃小店、紫藍天色、仍亮著的自助機。有海風、空地、懶坐的台階，也有趕工、失約與危險。
- 年代：日常街頭質感（街機、二手電器、影印傳單）混少量冷調電子（耳罩介面、控制器、巡檢設備）。確切年代、人口不交代。
- 視覺沿用 `style-guide.md`：極低多邊形、霧面平塗、低角度廣角鏡頭。
- 國際化混搭（參考攻殼機動隊、Cyberpunk 的氛圍，不照搬標誌元素）：垂直分層（上層企業塔、下層潮濕舊區、中間亂接的管線與招牌）、招牌混用漢字、假名、拉丁字母與虛構符號，不屬於任何一個國家；深藍紫色底配霓虹。

## 四、五條運作規則（城市為何如此荒謬）

| 規則 | 日常可見的結果 |
|---|---|
| 設備耐用，規格淘汰得快 | 貨車還能開，但接口停用，進不了新倉；街坊照樣改作他用 |
| 基建共用，使用權分散 | 一道門涉及屋主、承包商與公共通道，大家互相推責 |
| **卡匣存方法，實體件負責做事** | 技能「模式」可以抄傳，但穩定輸出仍要合適的核心與配件。**＝本作的技能系統（技能卡匣）** |
| 自動化做重複工作，人決定用途 | 機器可以巡線，但誰的貨可以搬走仍要有人負責 |
| 街區資訊有差異，也能互通 | 回收攤熟悉庫存，跑線的人知道入口，維修員知道哪個接點危險 |

## 五、勢力（敘事組織，不是陣營系統）

| 稱呼 | 想保住什麼 | 有用與麻煩之處 |
|---|---|---|

| **TURB 公司**（街坊俗稱「整件回收」） | 低成本集中回收、控制零件轉售渠道 | 能處理危險廢件，也會把仍可用的東西成批劃走（取消單、自動清場設備） |
| **散檔** | 各自的小生意、能用的設備與交換門路 | 攤主與工作間的俗稱，沒有統一領袖；互相幫忙，也會爭客、食言 |

壞人不靠制服、全黑配色或長篇宣言建立，要靠做事的方式。普通路人只是旁觀、避開或繼續生活。

## 六、敵人：人 + 失控設備 + 改裝體

不做有機生物怪、喪屍、異形，改為「失控的東西」，貼合疊域（設備淘汰、回收、加建）與低多邊形風格（箱形物件加幾隻腳，容易製作）。

| 類別 | 是什麼 | 用途 |
|---|---|---|
| **人** | 清場組（打工仔＋殺手） | 槍戰、壓迫感、關底頭目 |
| **失控設備** | 被廢棄或被壞卡匣影響的販賣機、洗衣機、冰箱、巡檢機械、自助機；會衝撞、噴射、模仿街上的東西 | 主要小怪；黑色幽默（販賣機衝過來還播放「謝謝惠顧」） |
| **改裝體** | 回收場把廢件亂拼成的東西。代表是「疊」：廢冰箱、單車、招牌疊成的巨物 | 精英與頭目；名字呼應「疊域」 |

世界觀理由：卡匣模式失控＝設備暴走，玩家使用的卡匣與它們是同一套東西。

**每章失控設備（草案）：**

| 章 | 失控設備 | 特點 |
|---|---|---|
| 1 橋底街 | 販賣機（衝撞）、回收箱（合上夾人，有預警）、晾衣架（揮動橫桿）、自助機（硬幣彈幕） | 動作簡單，教學用 |
| 2 散貨窗口 | 推車群（成串衝來）、膠箱（疊高再倒下）、舊音響（低音震波）、秤重機（壓扁地板） | 開始有範圍攻擊 |
| 3 倉樓 | 叉車（直線衝刺）、貨架（倒下封路）、封箱機（拋膠帶困住）、升降平台（跳上拍落） | 地形互動 |
| 4 高架繞路 | 路障機（升降閘）、巡檢無人機（懸停掃描）、電線團（甩動）、廣告牌（墜落） | 立體 |
| 5 停產測試場 | 測試假人（模仿玩家動作）、故障機偶（分裂）、壓力機（慢速大範圍）、測試車（定線來回） | 機關多 |

## 七、核心衝突與故事骨架

主題：**誰有權決定工具怎麼用、路讓誰走、被淘汰的東西還有沒有價值。** 不是「打倒大魔王」，而是一群不守規矩的少年少女，在被體制收數的日子裡，用鑽空子換一口氣，同時發現自己每次鑽空子，都落在身邊的人身上。

基調：日常、反社會（對象是規矩與體制）、冷面黑色幽默，中間留一點溫情（街坊、同伴、一頓午飯）。感覺對標《SLUMLORDZ SANDWICH》。

開場：玩家接一張**取消得太遲的回收單**，到清倉店搬走一批舊設備，箱子裡有一張沒有型號的**模式卡匣**。整件回收取消委託，清運員 Ren 上門要回整箱東西；自動回收設備連店家仍在使用的貨也一併算進去。清場組隨後追討卡匣。玩家一邊清路、一邊核對哪些貨屬於店家、尋找收貨編號，由此追查高架倉線上流通的模式。

| 章 | 玩家的目的 | 揭露 | 殺手頭目 |
|---|---|---|---|
| 1 橋底街 | 找收貨人、脫身 | 第一次模式改變 | TK-075「收據」 |
| 2 散貨窗口 | 找人鑑定與改裝 | 不同改裝流派；**散檔夜場、DJ 頭目** | TK-052「雨傘」 |
| 3 倉樓 | 進入受勢力控制的舊樓 | 委託開始有取捨 | TK-038「眼鏡」 |
| 4 高架繞路 | 繞過封鎖、跨區 | 場景放大；**車追逐演出** | TK-024「司機」 |
| 5 停產測試場 | 追查模式為何被封存 | 第一段主線收束 | TK-011「取消費」 |
| 6 貨運口 | 保住流通路線 | 留下可繼續探索的出口 | TK-000 總經理級殺手 |

第 2 至 6 章只是方向，等第 1 章玩法驗證後再細化。**結局由玩家的行為決定街區保不保得住**（Alan 已確認）。

## 八、四人如何進入世界

- 四人是同一街區的熟面孔，**各自一個人都可以獨力走完主線**（舊版原則）。
- **開局選角，如同 PoE2**：玩家選 Jax／Vee／Skye／Niko 其中一人，單人遊玩。其餘三人以街上熟面孔的身份露面，暫時不做夥伴；通關後可改玩另一個角色（Alan 已確認，此處為我的理解，待核對）。
- 四種解難方式對應四類障礙：

| 障礙 | 解法 | 角色 |
|---|---|---|
| 擋路的物件、牆、閘 | 打碎 | Jax |
| 設備、訊號、感測、電子鎖 | 覆寫 | Vee |
| 巡邏順序、人群、規則 | 打亂 | Skye |
| 大型機械、重型設備 | 支配 | Niko |

- **同一開場，四個接單理由**（草案）：

| 角色 | 為什麼接這張單 |
|---|---|
| Jax | 舊設備可以拆、可以改，有東西拆就去 |
| Vee | 卡匣是沒人收得回的工具，想研究 |
| Skye | 順手跑腿，看中卡匣好玩，也可以耍一耍清運員 |
| Niko | 箱子裡有可重組的零件與重型接口 |

## 九、氣氛與黑色幽默規則

### 粗俗與狠勁的表達（Alan 已確認，2026-10-30）
- **主角極少說話：** 四位主角不說台詞，只有極少量單字、笑聲、氣聲等短音（Jax 的笑聲、Vee 的呼氣、Skye 的輕哼、Niko 的「停」）。粗俗與狠勁用動作表達：冷眼、故意把對方的工作證丟開、拆掉對方的東西、慢慢把飯盒放高再出手。
- **NPC 可以粗俗：** 街坊、打工仔、殺手都可以刻薄、講狠話，但不是直白粗口。靠市井口氣、荒誕比喻、嘲諷與停頓。街坊口氣生活化；打工仔像職場抱怨；殺手的狠話反而客氣（「這單很快辦完，你那份另計。」）。
- **三級程度：** 日常（街坊）輕；戰鬥（清場組）中等，短而狠；頭目戰與高潮較重，但份量少。
- **界線：** 不用性暴力或性侮辱用語，不用針對種族、性別、殘疾的歧視性辱罵，也不用不適合 16 至 17 歲角色的侮辱手勢；狠勁的對象是對手與體制，不是弱者。狠勁之後要有後果。
- **分級：** 上架前需核對各平台（Steam、手機商店）對語言與暴力的分級要求。

### 一般規則
- **荒誕但後果是真的**：畫面不寫實暴力；少量暴力、反叛等成熟題材可以有，但四人是 16 至 17 歲，重點是友情、自由、逞強、失誤與成長，不寫成人式處決或性暴力。
- **官僚幽默，結果留在畫面**：設備攔住有收據的貨，旁邊的打印機照常印出「提高流通效率」。
- **鬆弛與突然爆發的對比**：空台場有人慢慢吃午飯，下一個路口設備突然動起來。亮色街景也有風險，冷色倉區也有人幫忙。
- **不是每個任務都是陰謀**：可以有送錯球鞋、荒唐但有效的接法等小事。
- 少用「修復一切」「每個人都被聽見」之類的暖心總結。

**日常小事件樣板（取自舊版，待修改，之後逐個試）：**

| 事件 | 內容 |
|---|---|
| 飯盒先放下（Ren） | 路被貨箱堵住，有動靜時先把飯盒放高，再一起清路；事後發現飯盒還在另一邊 |
| 買一送一邊（Vee） | 耳機買一送一，原來是一邊耳罩送另一邊不同型號；Vee 試聽後只問能否分開調節 |
| 不趕的那條路（Skye） | 指一條看似捷徑的繞路，自己從另一邊先到，歪嘴等對方發現；真有危險才收手 |
| 最後一口（Jax） | 飲品一放，見設備擋路就咧嘴笑，崩開後放聲大笑，杯子被震到另一張桌上 |
| 自動等你（Niko） | 叫機偶代自己排隊，店家叫本人取貨，他卻先命令機偶停下；控制一切反而慢了一步 |

## 十、清場組（黑衣人）、槍械、車追逐、打碟

靈感來自《SLUMLORDZ SANDWICH》的氣質（黑衣人、槍、車追逐、打碟）。只借氣質，不抄影片中的人物、組織或橋段。

### 清場組（偏殺手路線）
- **是什麼：** TURB 公司外判的清場隊，分兩層：
  - **底層（打工仔）：** 編號牌小兵、持槍手、駕駛。有禮貌、按單辦事，說「收到，已記錄」，被打倒會掉落工作證與飯盒。
  - **上層（殺手）：** 組長與每章頭目。安靜、專業、少話，接「合約」辦事；黑色幽默來自合約文化（「取消費另計」「完成率 97%」）。是真正令人有壓迫感的對手。
- **識別：** 黑西裝、工作證、耳掛對講機、臂上編號牌（編號越小越高級）；殺手各有招牌道具或習慣。
- **立場不單一：** 有打工仔私下放過玩家；有殺手對合約有底線，可成為後期關係線。
- **與四人的關係：** Jax 打爛他們的車與閘門，最容易令「得罪殺手」變成「街坊被針對」；Vee 干涉對講機與瞄準器；Skye 認得出他們用什麼槍，擅長玩弄巡邏編號與打卡時間；Niko 對裝甲貨車、起重車垂涎，想搶來控制。

**殺手頭目（草案，按章）：**

| 章 | 頭目 | 招牌 | 打法 |
|---|---|---|---|
| 1 | TK-075「收據」 | 蓋印機，每擊中你一下就蓋一個「已處理」 | 打爆印章即可削弱 |
| 2 | TK-052「雨傘」 | 黑傘既是盾也是散彈槍，下雨才肯開傘 | 逼他收傘後才能輸出 |
| 3 | TK-038「眼鏡」 | 動手前慢慢擦眼鏡，期間是攻擊窗口 | 打破眼鏡，他就失準 |
| 4 | TK-024「司機」 | 裝甲貨車 | 車衝過來，要閃避 |
| 5 | TK-011「取消費」 | 只講合約，每個階段加價 | 速度與彈幕逐階段升級 |
| 6 | TK-000 總經理級殺手 | 沒有招牌道具，最樸素、最危險 | 主線收束 |

### 槍械（已確認）
- 槍手是遠程敵人：持槍姿勢 → 瞄準線或短暫停頓（預警）→ 發射彈丸 → 閃避。難度低至中。
- 子彈是粗身色條；中彈是被打飛、掉帽、公文紙屑爆開，不寫實血腥；後果落在故事裡。
- 玩家方面只有 Skye 用槍，避免四人玩法重疊。

### 車追逐（已確認：只做演出）

## 十四、全遊戲命名規則（Alan 已確認方向，2026-10-30）

命名風格不只用於勢力，而是整個遊戲：體制與機器用型號感，人與生活保留人味，兩者並排出現，形成「日常但反社會」的反差。名稱與說明文字一律使用書面語。

### 總則
1. **三種語感：** 公司名（TURB）＝體制；型號（TK-075、CT-07）＝被編號的人與物；代號（ERRO-零）＝失控或地下的東西。
2. **官方名與街頭名並存：** 介面與告示寫官方名，角色與街坊口中說街頭名（例如 TURB 公司，街坊叫「整件回收」）。
3. **格式統一：** 英文字母加短橫加數字（或中文數字），不超過三段。
4. **玩家需要記住的東西**（技能、配件）用「中文功能名加型號」，不要只靠型號。
5. 英文只作品牌或型號，說明一律使用中文。
6. 名稱均為虛構；若日後商業發行，建議做一次簡單的商標查詢。

### 四種命名形式（按情況選用）
1. **全英文：** 品牌、公司、機器感的名稱，如 TURB、ERRO。適合體制與冷名字。
2. **中英混合：** 兼顧辨識與氛圍，如 TK 清場組、UCA-12 聯務署、ERRO-零。適合玩家需要記住的勢力與敵人。
3. **代號：** 英文加中文數字或符號，如 ERRO-零，像故障代碼或行動代號。適合失控或地下的東西。
4. **純數字或編號：** 如 075、TK-075，像員工編號或序號。適合被編號的人與量產物。

選用原則：玩家需要記住或會反覆接觸的，用中英混合；只作氛圍或背景的，可用全英文、代號或純數字；人與生活保留中文人名與俗稱。

### 各類別
| 類別 | 風格 | 範例 |
|---|---|---|
| 勢力 | 公司、機構、編號 | TURB 公司、UCA-12 聯務署、TK 清場組；「散檔」保留中文 |
| 地名與區域 | 人味為主，編號只作副標 | 橋底街（B1）、散貨窗口（C2）、倉樓（D3）、高架繞路（E4）、停產測試場（F5）、貨運口（G6） |
| 道具與配件 | 型號感 | 衝擊工具 HM-17、心靈介面 PS-03、模組步槍 R-9、維護工具 MT-44 |
| 卡匣（技能） | 型號加中文功能名 | CT-07 分裂、CT-12 連鎖 |
| 敵人：人 | 編號加綽號 | TK-075「收據」、TK-112 打工仔 |
| 敵人：設備 | 型號加功能名 | VD-04 販賣機、RB-09 回收箱；暴走後加 ERRO- 前綴，如 ERRO-VD-04 |
| 敵人：改裝體 | 代號感 | ERRO-零「疊」 |
| 角色與 NPC | 保留人味 | Jax、Vee、Skye、Niko、Bo、Ren、Ada；登記編號只在介面出現（如 Ren 的清運員編號 TK-208），對話中仍叫名字 |

### 已採用的預設（可修改）
1. TURB 公司是母公司，「整件回收」是街坊對它的俗稱。
2. 殺手頭目採用「TK-編號加綽號」，編號越小越高級，總經理級為 TK-000。
