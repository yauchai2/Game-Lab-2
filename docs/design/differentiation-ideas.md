# 與 PoE2 拉開差異：研究與構想

狀態：**Alan 已確認推薦方向（2026-10-30）**：(1) 卡匣配件槽（短街區 run＋基地，暫時擱置）、(2) 缺點天賦樹加後果帳、(3) 頭目四種解法。構想 3、5、8 也獲 Alan 接受（隨進度穿插加入）；第六節第 1 題 Alan 回答「三樣都想」（系統深度、黑色幽默、短 run 節奏），第六節第 2、3、4 題（短街區 run＋基地、死亡處理、借技）Alan 暫時擱置，尚未定案。Path of Exile 2（下稱 PoE2）的資料是我按所知整理，版本更新頻繁，細節以官方為準。對照設定：`world.md`（疊域、卡匣存方法、黑色幽默）、`characters.md`（四人缺點與核心動詞）、`game-plan.md`（類 PoE2、選一個角色、零基礎）。

## 一、PoE2 核心設計，一頁看完

| 系統 | PoE2 的做法 | 玩家得到的感覺 |
|---|---|---|
| 技能 | 技能寶石加輔助寶石，插入有連結的插槽，連結決定技能如何變化 | 組合 build 的創造感；但門檻高 |
| 天賦 | 一棵超大的被動樹（過千節點），加職業昇華 | 可能性無限；新手看了頭暈 |
| 裝備 | 白、藍、黃、暗金四級稀有度，詞綴有前綴、後綴與階級，靠通貨隨機改造 | 賭博式追裝；越後期越複雜 |
| 戰鬥 | 較慢、較重、有前搖，翻滾閃避，頭目招式有清楚提示 | 近似魂系動作，死亡要負責 |
| 頭目 | 多階段、讀招、走位為主 | 勝利感高 |
| 經濟 | 通貨即材料，玩家之間交易 | 長期目標，但新手容易迷失 |
| 內容結構 | 長戰役，之後進入無盡地圖終局 | 非常深，但個人開發者做不完 |

## 二、想保留與建議改動

**保留（這些是「PoE2 的味道」）：**
- 斜俯視 3D、滑鼠移動加技能鍵。
- 「技能加輔助改造」的組合樂趣（我們用卡匣包裝）。
- 有重量的戰鬥與頭目讀招。
- 每個職業有獨立身份（正好對應四人）。
- 稀有度分級（有「撿到好東西」的興奮）。

**改動（為什麼要改）：**

| PoE2 | 改成 | 理由 |
|---|---|---|
| 技能寶石加連結 | 技能卡匣加配件槽（簡化） | 貼合世界觀；少了連結的幾何關係，容易製作也容易理解 |
| 千節點巨型天賦樹 | 每人一棵小樹（約 30 至 40 點），加入「缺點」節點 | 零基礎也能做，每個選擇都看得到；缺點變成機制 |
| 隨機詞綴賭博 | 以「改裝」與「轉用」為主，少量隨機 | 符合「設備耐用、規格淘汰」；減少數值膨脹 |
| 長戰役加無盡地圖 | 一區一區的短街區行動，回到基地 | 個人開發可行；試玩版容易切分 |
| 玩家交易經濟 | 單機，用「單據」做貨幣，帶官僚幽默 | 不需要伺服器；有黑色幽默 |
| 魂系嚴肅調子 | 荒誕但後果是真的 | 與 PoE2 最大的分別，見下 |

## 三、類似 ARPG 值得借鏡的做法

| 遊戲 | 值得借鏡 | 如何用在我們這裡 |
|---|---|---|
| Hades | 短 run、每次選擇一個小強化、死亡後劇情推進 | 一區 10 至 15 分鐘，回基地有人跟你說話 |
| Diablo 4 | 城鎮據點有人氣、職業有專屬資源與機制 | Bo 商店作為據點；四人各有專屬機制 |
| Last Epoch | 每個技能自己一棵技能樹、製作裝備可預期 | 每個卡匣自己有一棵小樹；改裝不太靠運氣 |
| Vampire Survivors 類 | 自動攻擊、成長曲線爽快、操作簡單 | Niko 的機偶自動作戰；整體技能鍵少，利於手機 |

## 四、差異化構想（8 個）

難度指「零基礎個人開發者用 Godot 做到有多辛苦」：★ 容易、★★ 要花些時間、★★★ 不容易、★★★★ 很難。

### 1. 卡匣加配件槽（取代寶石連結）
- **玩家體驗：** 技能是一張「模式卡匣」，插入「控制器」，上面最多 2 個配件槽，配件改變技能行為（例如變成連發、延遲爆發、落地留下）。換配件即時看到差別。
- **扣連四人：** 世界觀「卡匣存方法，實體件負責做事」直接成立。每人起手卡匣不同：Jax 重擊、Vee 場域、Skye 投射、Niko 機偶指令。
- **難度：** ★★。用資料檔（Godot Resource）定義技能與配件，不必為每個組合寫程式。

### 2. 「缺點」天賦樹（缺點變成選擇）
- **玩家體驗：** 每人一棵小樹。樹上有「強力但有代價」的缺點節點，取得即解鎖強力招式，但會改變行為，例如 Jax 攻擊必定破壞地形（連自己要用的路也拆掉）；Vee 覆寫前不會預警隊友（單人遊玩下改為敵人更難預測）。
- **扣連四人：** 直接把「慾望—缺點—後果」變成成長選擇。
- **難度：** ★★。同樣用資料檔，每個缺點要手寫少量規則。

### 3. 單據經濟（官僚幽默貨幣）
- **玩家體驗：** 貨幣是單據、蓋章、取消單。商人不收錢，收「簽名」；掉落物可能附帶「取消得太遲」標記，過一陣子整件回收會上門追討（要你守住或交還）。拿走的貨有風險，不是純賺。
- **扣連四人：** 與開場「取消得太遲的回收單」及 Ren 上門一脈相承；黑色幽默主要靠這套系統表達。
- **難度：** ★★。核心是計時器與事件；視覺靠介面文字。

### 4. 後果帳（地圖永久改變）
- **玩家體驗：** 你打爆的閘、封住的巷，在同一輪遊戲裡一直保持原樣。有些後果有好處（近路），有些有壞處（敵人來路改變、街坊態度）。
- **扣連四人：** 缺點事件變成機制：Jax 打爆通道、Skye 的惡作劇封巷、Vee 覆寫路線、Niko 搬走重型設備。
- **難度：** ★★★。要記錄每個物件的狀態並存檔；試玩版可只做 3 至 5 個關鍵物件。

### 5. 每人專屬閃避動詞
- **玩家體驗：** 把 PoE2 的翻滾換成四種身法：Jax 滑板衝（滑過地面破壞物件）、Vee 短距離「覆寫位移」、Skye 鬼步（留下殘影誘敵）、Niko 與機偶換位。
- **扣連四人：** 與興趣直接連結（滑板、舞步、機偶）。
- **難度：** ★★。動畫要做四套；先用同一動畫加不同特效做灰盒測試。

### 6. 頭目有四種解法
- **玩家體驗：** 同一個頭目（例如轉運口那部大型設備）有四個「弱點接口」：打碎裝甲、覆寫控制盤、打亂巡邏、支配搶控。選了角色後，你玩的解法不同；同樣一戰，四人有四種打法與故事。
- **扣連四人：** 完全對應「四種解難方式」。
- **難度：** ★★★。頭目招式要做；建議第一個頭目只做 2 至 3 個階段，先由 Jax 開始，之後逐人加入。

### 7. 街區 run 加基地（Hades 式節奏）
- **玩家體驗：** 一次出擊＝一段街區，約 10 至 15 分鐘，完成後回到 Bo 商店，用單據改裝、與街坊聊天。死亡不是懲罰，只是「今天收工」，保留部分單據。
- **扣連四人：** 其餘三人在基地以街坊身份出現，可以「借技」（一次出擊借用他們的一張卡匣），解決「選了角色就看不到其他人」的問題。
- **難度：** ★。結構簡單；對試玩版最友善。

### 8. 機偶自動化（Niko 專屬，Vampire Survivors 味道）
- **玩家體驗：** Niko 不直接出手，而是編排機偶自動戰鬥。操作少、策略多，近似「組隊形」。
- **扣連四人：** 把「支配」變成與其他三人完全不同的玩法，而且操作少，利於手機。
- **難度：** ★★★。要做簡單的敵我 AI；可以晚一點再加。

## 五、推薦優先方向（2 至 3 個）

1. **構想 1＋7（卡匣配件＋短街區 run）：** 這兩個是骨架，直接配合試玩版「一條街＋一個角色」，也夠接近 PoE2 組合 build 的核心感覺，做得到。
2. **構想 4＋2（後果帳＋缺點樹）：** 這一組是與 PoE2 最大的差異，也是四人設定最獨特的地方。可以先做一個關鍵物件（Jax 打爆閘）來驗證。
3. **構想 6（頭目四種解法）：** 做完 Jax 解法後，逐人加入。這是最強的招牌，但耗時，所以排第三。

構想 3（單據經濟）、5（專屬閃避）、8（機偶）可以隨進度穿插。
