# 同 PoE2 拉開差異：研究同點子

狀態：**Alan 已確認推薦方向（2026-10-30）**：(1) 卡匣配件槽 + 短街區 run、(2) 毛病天賦樹 + 後果帳、(3) Boss 四種解法。點子 3、5、8 亦獲 Alan 接受（隨進度穿插加入）；第六節第 1 題 Alan 答「三樣都想」（系統深度、黑色幽默、短 run 節奏），其餘仍待答。Path of Exile 2（下稱 PoE2）資料係我按所知整理，版本更新頻密，細節以官方為準。對照設定：`world.md`（疊港、卡匣存方法、黑色幽默）、`characters.md`（四人缺點同核心動詞）、`game-plan.md`（類 PoE2、揀一個角色、零基礎）。

## 一、PoE2 核心設計，一頁睇晒

| 系統 | PoE2 點做 | 玩家得到嘅感覺 |
|---|---|---|
| 技能 | 技能寶石 + 輔助寶石插入有連結嘅插槽，連結決定技能點變化 | 砌 build 嘅創造感；但門檻高 |
| 天賦 | 一棵超巨被動樹（過千節點），加職業昇華 | 無限可能；新手睇到頭暈 |
| 裝備 | 白／藍／黃／暗金四級稀有度，詞綴有前綴後綴同階級，靠通貨隨機改造 | 賭博式追裝；愈後期愈複雜 |
| 戰鬥 | 較慢、較重、有前搖，翻滾閃避，Boss 有清楚招式提示 | 似魂系動作，死亡要負責 |
| Boss | 多階段、讀招、走位為主 | 勝利感高 |
| 經濟 | 通貨即係材料，玩家間交易 | 長期目標，但新手易迷失 |
| 內容結構 | 長戰役，之後進入無盡地圖終局 | 好深，但個人開發者做唔晒 |

## 二、想保留 vs 建議改動

**保留（呢啲係「PoE2 味」）：**
- 斜俯視 3D、滑鼠移動加技能鍵。
- 「技能 + 輔助改造」嘅砌 build 樂趣（我哋用卡匣包裝）。
- 有重量嘅戰鬥同 Boss 讀招。
- 每個職業有獨立身份（正好對應四人）。
- 稀有度分級（有「執到好嘢」嘅興奮）。

**改動（點解要改）：**

| PoE2 | 改成 | 理由 |
|---|---|---|
| 技能寶石 + 連結 | 技能卡匣 + 配件槽（淺化） | 貼世界觀；少咗連結幾何，易做易明 |
| 千節點巨型天賦樹 | 每人一棵細樹（約 30 至 40 點），加「毛病」節點 | 零基礎好做，每個選擇都睇得到；缺點變成機制 |
| 隨機詞綴賭博 | 以「改裝」同「轉用」為主，少量隨機 | 符合「設備耐用、規格淘汰」；減數值爆炸 |
| 長戰役加無盡地圖 | 一區一區嘅短街區行動，返基地 | 個人開發可行；試玩版易切 |
| 玩家交易經濟 | 單機，用「單據」做貨幣，帶官僚幽默 | 唔使做伺服器；有黑色幽默 |
| 魂系嚴肅調子 | 荒誕但後果真 | 同 PoE2 最大分別，見下 |

## 三、類似 ARPG 值得偷嘅做法

| 遊戲 | 值得借 | 點用喺我哋度 |
|---|---|---|
| Hades | 短 run、每次選擇一個小強化、死咗有劇情推進 | 一區 10 至 15 分鐘，返基地有人同你講嘢 |
| Diablo 4 | 城鎮 hub 有人氣、職業有專屬資源／機制 | 包記雜貨做 hub；四人各自專屬機制 |
| Last Epoch | 技能樹每個技能自己一棵、製作裝備可預期 | 每個卡匣自己有細樹；改裝唔太靠運氣 |
| Vampire Survivors 類 | 自動攻擊、成長曲線爽、操作簡單 | Niko 嘅機偶自動作戰；整體少技能鍵，利於手機 |

## 四、差異化點子（8 個）

難度指「零基礎個人開發者用 Godot 做到幾辛苦」：★ 容易、★★ 要啲時間、★★★ 唔易、★★★★ 好難。

### 1. 卡匣 + 配件槽（取代寶石連結）
- **玩家體驗：** 技能係一張「模式卡匣」，插入「控制器」，上面最多 2 個配件槽，配件改變技能行為（例如變成連發、延遲爆發、落地留低）。換配件即時見到分別。
- **扣連四人：** 世界觀「卡匣存方法，實體件負責做事」直接成立。每人起手卡匣不同：Jax 重擊、Vee 場域、Skye 投射、Niko 機偶指令。
- **難度：** ★★。用資料檔（Godot Resource）定義技能同配件，唔使為每個組合寫程式。

### 2. 「毛病」天賦樹（缺點變選擇）
- **玩家體驗：** 每人一棵小樹。樹上有「強力但有代價」嘅毛病節點，取得即解鎖大招式，但改變行為，例如 Jax 攻擊必定破壞地形（連自己要用嘅路都拆）；Vee 覆寫前唔會預警隊友（單人下改為敵人更難預測）。
- **扣連四人：** 直接把「慾望—缺點—後果」變成成長選擇。
- **難度：** ★★。一樣用資料檔，每個毛病要手寫少量規則。

### 3. 單據經濟（官僚幽默貨幣）
- **玩家體驗：** 貨幣係單據、蓋章、取消單。商人唔收錢收「簽名」；掉落物可能附帶「取消得太遲」標記，過一陣整件回收會上門追返（要你守住或交還）。拎走嘅貨有風險，不是純賺。
- **扣連四人：** 同開場「取消得太遲嘅回收單」同 Ren 上門一脈相承；黑色幽默主要靠呢套系統表達。
- **難度：** ★★。核心係計時器同事件；視覺靠介面文字。

### 4. 後果帳（地圖永久改變）
- **玩家體驗：** 你打爆咗嘅閘、封咗嘅巷，喺同一輪遊戲入面一直係咁。有啲後果有好處（近路），有啲有壞處（敵人來路改變、街坊態度）。
- **扣連四人：** 缺點事件變成機制：Jax 打爆通道、Skye 嘅惡作劇封巷、Vee 覆寫路線、Niko 搬走重型設備。
- **難度：** ★★★。要記低每個物件狀態同存檔；試玩版可只做 3 至 5 個關鍵物件。

### 5. 每人專屬閃避動詞
- **玩家體驗：** PoE2 嘅翻滾，換成四種身法：Jax 滑板衝（滑過地面破壞物件）、Vee 短距離「覆寫位移」、Skye 鬼步（留殘影誘敵）、Niko 同機偶換位。
- **扣連四人：** 同興趣直接連（滑板、舞步、機偶）。
- **難度：** ★★。動畫要做四套；先用同一動畫加不同特效灰盒測試。

### 6. Boss 有四種解法
- **玩家體驗：** 同一個 Boss（例如轉運口嗰部大型設備）有四個「弱點接口」：打碎裝甲、覆寫控制盤、打亂巡邏、支配搶控。揀咗角色後，你玩嘅解法唔同；同樣一戰，四人打法四種故事。
- **扣連四人：** 完全對應「四種解難方式」。
- **難度：** ★★★。Boss 招式要做；建議第一個 Boss 只做 2 至 3 個階段，由 Jax 先行，之後逐人加。

### 7. 街區 run + 基地（Hades 式節奏）
- **玩家體驗：** 一次出擊 = 一段街區，約 10 至 15 分鐘，完咗返包記雜貨，用單據改裝、同街坊傾偈。死亡唔係懲罰，只係「今日收工」，保留部分單據。
- **扣連四人：** 其餘三人喺基地以街坊身份出現，可以「借技」（一次出擊借一張佢哋嘅卡匣），解決「揀咗角色就睇唔到其他人」嘅問題。
- **難度：** ★。結構簡單；對試玩版最友好。

### 8. 機偶自動化（Niko 專屬，Vampire Survivors 味）
- **玩家體驗：** Niko 唔直接出手，而係編排機偶自動戰鬥。操作少，策略多，近似「砌隊型」。
- **扣連四人：** 把「支配」變成同其他三人完全唔同嘅玩法，而且操作少，利於手機。
- **難度：** ★★★。要做簡單敵我 AI；可晚點再加。

## 五、推薦優先方向（2 至 3 個）

1. **點子 1 + 7（卡匣配件 + 短街區 run）：** 呢兩個係骨架，直接配合試玩版「一條街 + 一個角色」，又夠似 PoE2 砌 build 嘅核心感覺，做得到。
2. **點子 4 + 2（後果帳 + 毛病樹）：** 呢組係同 PoE2 最大嘅差異，亦係你四人設定最獨特嘅地方。可以先做一個關鍵物件（Jax 打爆閘）去驗證。
3. **點子 6（Boss 四種解法）：** 做完 Jax 解法後，逐人加。呢個係最強嘅招牌，但耗時，所以排第三。

點子 3（單據經濟）、5（專屬閃避）、8（機偶）可以隨進度穿插。
