# PoE 2 研究與優化計劃

狀態：草案（2026-10-30），等 Alan 確認優先次序。文中中文一律書面語。

**資料來源說明：** Alan 提供的 YouTube 影片（DLNhbIlgF5k）無法從雲端環境讀取（被 YouTube 擋下，沒有字幕可取），所以本文沒有引用該影片的任何內容。下面的 PoE 2 機制來自 Alan 在對話中貼的截圖（地上掉落名牌、裝備頁、鏡頭畫面）、公開資料與一般認知；細節數值未逐一核實，只用來決定方向，不照抄數字。若影片有特別想參考的段落，請告訴我時間點或貼截圖。

## 一、PoE 2 的核心機制（與本作相關的部分）

| 系統 | PoE 2 做法 | 為何好玩 |
|---|---|---|
| 技能 | 技能寶石，每個技能插輔助寶石改變效果；技能列有多個按鍵（滑鼠左右鍵、Q／E／R／T 等） | build 的主軸；同一技能可以有完全不同玩法 |
| 資源 | 魔力（放技能）與精魂（常駐增益佔用） | 限制堆疊，逼玩家取捨 |
| 閃避 | 空白鍵翻滾，有無敵與短冷卻 | 動作感；頭目預警就是為了讓人閃 |
| 裝備 | 白／藍／黃／傳奇；前綴後綴詞綴、階級（T1–T5）、物品等級決定可出什麼詞綴 | 掉落有驚喜，也有「對 build 有用才值錢」 |
| 製作 | 一組通貨（轉化、增幅、點金、混沌、崇高等）各自改變裝備 | 玩家用資源賭、修、練裝備 |
| 角色強度 | 護甲／閃避／能量護盾、四種抗性、被動天賦樹、昇華職業 | 長期成長；防禦同樣是 build 一部分 |
| 狀態 | 點燃、冰凍、感電、暈眩（頭目有「破防」條） | 戰鬥有節奏，不只是打血量 |
| 怪物 | 白／魔法／稀有怪帶詞綴，群怪帶頭領；頭目有多階段與預警 | 每場遇敵都不同；稀有怪是掉落重點 |
| 補給 | 藥劑（生命／魔力）靠擊殺回充 | 戰鬥中的資源管理 |
| 進度 | 章節 → 傳送點 → 終局地圖（水路石）；倉庫、商人、任務 | 短期目標與長期循環 |
| 介面 | 左下紅球（生命）、右下藍球（魔力）、底部技能列與藥劑、右側任務目標、人形裝備頁加大格背包、掉落名牌與過濾器 | 資訊清楚；一眼看懂掉了什麼 |
| 鏡頭 | 固定斜向等距，滾輪縮放，頭目戰拉遠 | 已實作 |

## 二、本作現況對照

已有：斜向等距鏡頭、WASD、衝刺、自動普攻（刻意保留）、2 張技能卡匣各 2 槽配件、12 件配件、14 種裝備、5 個裝備欄、三級稀有度與隨機詞綴、單據（重擲／升級／拆解）、掉落名牌、PoE 式裝備頁、據點與頭目、死亡保留成長、存檔、第一章流程。

與 PoE 2 的主要差距：

1. 技能只有一個大技加衝刺，沒有技能列，build 空間窄。
2. 詞綴沒有階級與物品等級，掉落感覺平。
3. 敵人只有一種，沒有魔法／稀有怪，掉落沒有「驚喜點」。
4. 頭目沒有破防條，戰鬥只有血量與預警。
5. 沒有補給（藥劑）、沒有防禦屬性（抗性、護甲）、沒有狀態效果。
6. 沒有倉庫、商人，單據只有一種用途集中在工作枱。
7. 介面沒有生命球、小地圖、傷害數字、敵人血條；名牌沒有「顯示全部」快捷鍵與點擊撿取。

## 三、哪些不照搬（已定方向）

- 不做三揀一升級、不做開箱獎勵（隨機獎勵自動給）。
- 保留自動普攻，不做 PoE 的「手動左鍵攻擊」。
- 不做龐大的被動天賦樹；長期成長用「裝備＋配件＋毛病成長」承擔。
- 世界觀與語氣見 `world.md`：藥劑改為街頭日常物（例如飲料、便當），技能名與詞綴用疊域用語。

## 四、優化計劃（按價值與成本排序）

### 第 A 階段：手感與讀感（成本低，立即有感）
1. **傷害數字與敵人血條**：命中即時反饋，是所有動作 RPG 的基本。
2. **掉落名牌強化**：Alt（或長按）顯示全部、點名牌撿取、名牌過濾（只顯示藍色以上）。
3. **頭目破防條**：頭目被連續命中累積「破防」，滿了暈眩數秒，讓玩家有明確的爆發窗口；與預警重擊對應。
4. **生命球與資源球**：左下生命球、右下技能資源球，取代左上血條。
5. **小地圖或目標指向**：第一章街區小，先做目標箭頭即可。

### 第 B 階段：build 深度（核心賣點，成本中）
1. **技能列擴充到 4 個按鍵（Q／E／R／F）**，技能以「卡匣」形式掉落或由商店購買；每張卡匣有 2 個配件槽（現有機制不變）。
2. **詞綴階級與物品等級**：區域與敵人等級決定可出現的階級，後期區域出更高階詞綴。
3. **魔法／稀有怪**：稀有怪帶 1–3 個怪物詞綴（快速、護盾、爆炸、召喚），掉落機率與稀有度加成；是掉落的主要驚喜來源。
4. **狀態與抗性**：先做燃燒、減速、暈眩三種，配件與裝備可附帶；抗性放第二輪。
5. **補給**：兩個補給欄（回血、短暫增益），擊殺回充；用日常物命名。
6. **資源上限**：技能耗用「資源」（可命名為「勁」），限制同時開太多技能，逼取捨。

### 第 C 階段：循環與長期（成本高，等 A、B 穩定）
1. **倉庫與商人**：Bo 的商店提供倉庫、買賣、用單據兌換；對應第一章結算的「照單交還／留下貨」選擇成為經濟取捨。
2. **多一種通貨**：目前單據包辦一切；可拆成「單據」（升級）與「零件」（重擲），讓通貨決策更有層次。先做一種，視測試再加。
3. **終局循環**：通關後解鎖「重複街區（階級提升）」，類似水路石，提供長期目標。
4. **第二章與第二位主角全面開放。**

## 五、建議的下一步

先做第 A 階段（傷害數字、血條、頭目破防條、生命球），再做第 B 階段的「技能列擴充」與「魔法／稀有怪」，這兩項最能放大 build 與掉落的樂趣。
