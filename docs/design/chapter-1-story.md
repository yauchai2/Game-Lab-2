# 第一章：吃完再說（修訂版大綱）

狀態：草案，等 Alan 確認。來源是 Alan 2026-10-30 提出的《街外有事》第一章大綱；本檔把它與現有設定、已做的遊戲原型對照，改好衝突位，並標明分階段製作。遊戲暫名《街外有事》（Alan 暫定），章名由「食完先講」改為書面語「吃完再說」。

本檔只描述第一章（開機到第一章結束，目標約 2 至 3 小時）。世界背景見 `world.md`，角色見 `characters.md`，第一區舊流程見 `first-district.md`（本檔通過後，它會被併入第六節的「街」與「首戰」，屆時再整理，現階段不改）。全部文字使用書面語；四位主角不說台詞，只有極少量短音。

## 一、一句話

**你只是想出門買材料、做完一個三明治，結果整個街區開始追捕你。**

核心感覺：生活細節與誇張動作放在一起（狹窄廚房、舊沙發、當舖、雜貨店、維修零件；門外是密密麻麻的高架橋、黑西裝追兵與漫畫式衝擊效果）。玩法是有 PoE 式裝備與技能組合深度的街頭動作 RPG。

### 做不到或風險較大

1. **主管三階段加場地重組**：製作量大，建議先做兩階段，第三階段用演出與弱點暴露簡化。
2. **選角場景「無縫換人」**：四人各有動畫與互動，建議先做靜態選角畫面。
3. **「第一章主線共用，但對白與動畫因角色而變」**：對白已因主角不說話而大幅減少，動畫差異集中在開場多士爐與少數機關，可行但要排在階段 3。
4. **2 至 3 小時內容**：需要至少 3 個新地圖區域、5 至 6 種新敵人、1 個中頭目、1 個章末頭目，需要分階段。

## 三、世界設定的調整

保留疊域設定，只新增一個制度：

- **住戶登記制度：** 居住、用電、交通與交易都綁定在一套地址登記上，由 UCA-12 聯務署管理。高架橋下的舊街區正被逐步「清除」：地方實際存在，但門鎖、販賣機、供電與交通設施會開始拒絕居民。
- **TURB 公司負責執行清除**：TK 清場組上門回收「未登記物件」，包括人。
- **核准模組：** 清場組用來鎖定目標的標記裝置（型號感命名，如 CT-31 鎖定模組）。拆下後可作為配件改裝武器，屬於卡匣配件系統的一種。

## 四、修訂版大綱

標記說明：**【階段 1】**＝垂直切片就要做；**【階段 2】**＝擴充；**【階段 3】**＝最後做。

### 1. 開機：主角還在睡【階段 1】
- 主畫面是高架橋下的一間小屋。風扇有點吵，冰箱偶爾震兩下。窗簾被經過的車燈照亮，桌上有半個三明治、一張欠費單，以及一個拆開的電子裝置。
- 角色攤在沙發上，電視播著廣告：「本市所有問題，都可以透過登記解決。」
- 選「新遊戲」，門外有人拍門：「醒了嗎？你的車又擋住別人做生意。」
- 角色伸手拿遙控器，按幾次沒反應，最後拍一下，畫面才亮。
- **玩家第一個操作就是拍醒電視。** 這個動作成為之後「重擊與互動」的第一個提示。
- 沒有世界歷史旁白。

### 2. 選角：誰今天下樓【階段 3，階段 1 用簡化版】
- 合租單位是選角場景。四人各做各的事：修車、睡覺、做早餐、拆機件。
- 點選角色，他會看向鏡頭，並用自己的方式處理同一件事：一台壞掉的多士爐。四種方式都不用說話：

| 角色 | 處理方式 | 帶出的打法 |
|---|---|---|
| Jax | 拍兩下，再把發熱線接上護臂 | 重擊、蓄力、電擊 |
| Skye | 快速拆件，用彈簧彈出卡住的麵包，順手拋給別人 | 位移、連擊、投擲、槍械 |
| Niko | 放出一隻小機偶爬進去修理 | 裝置、召喚、陷阱 |
| Vee | 指尖點一下腕部介面，多士爐隔空啟動 | 範圍控制、干擾、連鎖 |

- **階段 1 簡化：** 只有 Jax，新遊戲直接進入第 1 節。**階段 2 加入 Skye；階段 3 才做完整選角場景與無縫換人。**
- 第一章主線共用；差異集中在開場多士爐動畫、室友的反應與少數機關的處理方式。

### 3. 前十分鐘：早餐教學【階段 1】
- 主角打開冰箱：兩片麵包、一瓶不知道還能不能喝的牛奶，最重要的餡料沒有了。
- 室友隔著房門說：「我吃了。樓下買吧，順便幫我拿一件東西。」
- 第一個任務：**買午餐。** 去樓下雜貨店買材料。
- 落樓前，在屋內自然完成幾個動作：
  - 跨過地上的電線，學短距離閃避。
  - 推開擋門的雜物，學互動。
  - 從工具架挑起始武器。
  - 在工作枱換一次簡單零件。
- 工具架上沒有神兵，只有扳手、改裝釘槍、壞掉的音響模組這類有生活來源的裝備。
- 打開門，鏡頭由室內近景拉到正常遊戲視角，街景完整展開，遊戲標題這時才出現。

### 4. 第一條街：先認識，再拆爛【階段 1：雜貨店與街道；階段 2：其餘地點】

| 地點 | 第一次去的作用 | 後續用途 |
|---|---|---|
| Bo 商店（雜貨店） | 買食物、認識店員機械人 | 補給、街坊委託 |
| 當舖 | 替室友拿件 | 裝備買賣、估價、特殊物品 |
| 修車檔 | 移走擋路的車 | 改裝、移動能力 |
| 天台 | 認識街坊、看到城市 | 練習區、捷徑、角色事件 |
| 自助洗衣店 | 可選的小插曲 | 第一個地下入口（階段 2 之後） |

- 頭段容許玩家散步、偷聽、摸奇怪的物件。有些 NPC 請你幫小忙，但不會一下樓就彈出十個任務標記。
- 新增 NPC：店員機械人（雜貨店，暫名 CL-03）、當舖老闆、修車檔師傅、天台街坊。沿用 Bo（商店店主）、Ren（臨時清運員）、Ada（聯務署外勤技術員）。

### 5. 引爆事件：你的房子「不存在」【階段 1】
- 主角買完材料，回程見到幾個黑西裝人站在樓下，拿著一台小機器對著大樓掃描。
- 黑西裝：「住戶資料更新。你的地址已被撤銷。」（主角不說話，只是停下腳步，抬頭望向自己的窗口。）
- 黑西裝：「系統顯示，您沒睡過。」
- 第一章目標：**找回原始住戶紀錄，阻止自己的房子與整條街被清除。**
- 玩家此刻關心的是家、室友與剛買回來的午餐，更大的陰謀留待之後揭開。

### 6. 第一場戰鬥：雜貨店門口【階段 1】
- 黑西裝人想帶走主角，爭執撞翻雜貨店貨架。店員機械人伸手阻止，隨即被拔掉電源。
- 最初只有兩個敵人：一個近身抓人，攻擊前會整理袖口；一個用掃描器瞄準，地面出現清楚的矩形範圍。
- 玩家可以正常攻擊，也可以踢動購物籃、推倒貨架、打壞燈牌讓敵人短暫觸電。**場景互動是額外選擇，基本打法同樣可靠。**
- 打完後，主角把店員機械人重新插上電。它說：「謝謝。你剛才壓爛了那箱水果，照價計算。」

### 7. 第一次掉寶：敵人的工具變成你的玩法【階段 1】
- 敵人掉落「核准模組」（鎖定裝置）。裝上玩家武器後，可以改變一招技能：

| 改法 | 實際效果 |
|---|---|
| 追蹤 | 攻擊會輕微追向被標記的敵人 |
| 連線 | 標記兩個敵人，傷害可部分傳導 |
| 超載 | 消耗標記，造成一次破防爆發 |

- 玩家當場試用，章節早期可以免費轉換。掉落畫面只突出「玩法改變」與主要數值，詳細資料再展開。零件保留原本外觀：膠殼、標籤、螺絲，以及一粒仍在閃的指示燈。
- 核心交付：**你可以拆走這個世界用來管住人的工具，再改成自己的武器。**
- 與現有系統的關係：核准模組屬於配件，用現有的卡匣配件槽、掉落與工作枱即可。

### 8. 第一章中段：三個地方，一條街的秘密【階段 2】
當舖老闆說，原始紀錄可能還留在高架橋上面的舊管理站。上去之前，要先恢復通行證，並找到能讀取紀錄的設備。玩家可自由決定前兩區的先後，完成後前往第三區。

| 區域 | 玩家做什麼 | 戰鬥與成長 |
|---|---|---|
| 後巷維修場 | 找回被收走的通行零件 | 首次遇到裝甲敵人，學習破防 |
| 天台接駁區 | 借街坊的天線接通舊網絡 | 多層路線、遠程敵人、首個技能分支 |
| 高架橋下管理站 | 查出紀錄被送去哪裡 | 敵人組合戰、中頭目、劇情轉折 |

- **後巷維修場：** 大量堆疊的廢車、活動鐵板與拆件機械。可以有幾條支路，但通往目標的方向由起重機剪影與運作聲引導。失控設備沿用世界觀第六節（叉車、貨架、封箱機等）。
- **天台接駁區：** 比較明亮，有晾衣服、盆栽與改裝天線。玩家遇到真正住在這裡的人，也看到城市另一面：遠處乾淨整齊的高樓，與腳下層層加建的舊屋。
- 一位街坊不肯借天線，因為主角早上移車時弄壞了他的東西。玩家可以修理、賠償，或走較危險的路。早段的小事開始有回應。
- Ada 在管理站提供讀取設備的方法（沿用 Ada 的設定）。

### 9. 中頭目：TK-075「收據」（收件員）【階段 1 的終點，或階段 2】
- 負責「回收未登記物件」的殺手頭目，身上掛滿封條、伸縮帶與壓縮箱，手持蓋印機。
- 招式：
  - 把場地一部分貼上封條，短暫封鎖。
  - 用伸縮帶拉玩家靠近。
  - 把散落物件壓成方塊，再推出去攻擊。
- 玩家可以打斷伸縮帶、破壞封條機，或直接攻擊本體。維修場學到的破防在此特別有用。
- 打敗後，他的機器印出一張長到拖地的收據，上面寫著：**待處理物件：整條街。** 主角此時才知道，家裡出問題是大規模清除行動的一部分。
- 沿用現有設定：他不死，禮貌離開（`first-district.md`）。

### 10. 返街：你幫過的人開始幫你【階段 2】
- 回到據點，氣氛有變：閘機不認人，部分店舖斷電，黑西裝人開始封住出口，街坊在路中間拉長拖板，共用剩下的電。
- 幫過的人會回報：被救的店員機械人提供補給；找回工具的修車師傅替你加裝一個零件；天台街坊用燈號指出安全路線。**主線必需工具一定取得到，支線只改變出發前的支援與場面。**
- 當舖老闆拼出資料：原始街區紀錄正由一輛行政運輸車送走，車隊即將駛上高架橋。
- 主角回屋拿頭盔，桌上的材料已經擺好。室友問：「還做不做？」主角不說話，只是戴上頭盔，指了指桌上的材料（意思：回來再做）。

### 11. 章末高潮：追回自己的街【階段 3】
保留影片公路動作的活力，但控制玩法變化幅度，讓玩家一路堆起來的 Build 仍然有用。

| 階段 | 玩家操作 | 製作分期 |
|---|---|---|
| 衝出封鎖線 | 用正常戰鬥突破路障，掩護室友發動車輛 | 階段 2 可先做 |
| 高架橋追逐 | **純演出**（低角度、廣角、速度線）；室友 NPC 駕駛，玩家不操作 | 階段 3 先做 |
| 登上運輸平台 | 回到穩定的戰鬥場地，挑戰章末頭目 | 階段 3 |
| （可選升級）車廂平台戰 | 在移動中的車廂平台上戰鬥：近戰打靠近的追兵、遠程打壞裝置、召喚物附在車上 | 階段 3 之後，視製作量決定 |

- 不做駕駛，不要求玩家掌握賽車操作。追逐段約 3 至 5 分鐘，有清楚的檢查點。

### 12. 章末頭目：TK-060「領帶」（主管）【階段 3】
極度整齊、表情平靜的黑西裝人，打得再激烈也會先拉直領帶。在運輸車展開的平台上進行。

- **第一階段：標準程序。** 盾牌、射擊與追蹤標記。招式規律清楚，考驗玩家認不認得前面遇過的敵人機制。
- **第二階段：現場重組。** 把貨箱、閘門與機械臂重新排列，改變場地。玩家可以打壞固定扣，保留自己需要的空間。
- **第三階段：程序失效。** 街坊遠端傳入大量互相矛盾的舊紀錄：同一個地址有十幾個名字、樓梯被登記成房間、天台既是花園又是貨倉。主管無法分類，攻擊出現破綻，但節奏更急。
- 最後一擊由玩家打出。鏡頭短暫切成影片那種誇張透視，黃橙色衝擊圖形炸開，再立刻回到正常視角。**強烈視覺效果集中在高潮，平時保持戰場清晰。**
- 製作建議：階段 3 先做第一、二階段；第三階段先用演出與弱點暴露簡化。

### 13. 結局：終於吃得上【階段 3】
- 玩家帶著紀錄回街，設施逐個恢復運作：雜貨店燈亮了，閘門開了，天台的收音機有聲音。街坊把不同地方找來的材料放在桌上，幫主角完成那個三明治。
- 第一章最後一個操作：**坐下，吃。**
- 吃完，主角把紀錄裝置隨手接上舊電視。畫面顯示一張城市地圖：自己的街恢復了，但遠處仍有大量街區逐個熄滅；其中一個正好是室友以前住的地方。
- 房間裡安靜了一陣。室友指著畫面：「……明天可能要早點起來。」
- 第一章完成。第二章從「保住這條街」擴展到「去找其他被抹走的地方」。
