# 開啟 Jax 試玩版（Godot）

專案已經建好，你**不需要自己搭場景**，只要安裝 Godot 並開啟專案。

## 1. 安裝 Godot

1. 前往 https://godotengine.org/download ，下載 **Godot 4.4 或以上的標準版（Standard，不是 .NET）**。
2. 解壓縮 zip，裡面有一個 `.exe`，**不需要安裝**，雙擊即可啟動。放在 repo 以外的位置（例如 `C:\Godot\`）。

## 2. 取得專案

用 Git 或 GitHub Desktop 把 `Game-Lab-2` repo 下載到電腦（切換到 PR #1 的 branch `claude/project-thread-0f5oar`，合併後使用 `main`）。

## 3. 開啟與試玩

1. Godot 啟動後按 **Import**，選擇 repo 根目錄的 `project.godot`，按 **Import & Edit**。（第一次會自動匯入 Jax 模型，等幾秒。）
2. 按右上角 **▶**（`F5`）。
3. 滑鼠**左鍵**點擊地板，Jax 走過去；**按住左鍵**會一直跟著游標移動（鏡頭跟隨，有走路動作）。
4. 綠色方塊敵人會一波波從四周追過來（每波多一隻），按 **Q** 或滑鼠**右鍵**施放「拆場」重擊：彎身蓄力後放出衝擊環，3.5 米內的敵人受傷並被擊退（敵人被打 2 下即死；第 2 波起出現紫色遠程敵人，會保持距離射出飛彈，冷卻 1.5 秒）。
5. 按 **空白鍵** 向滑鼠方向滑板衝刺（約 5 米，衝刺期間無敵，冷卻 1 秒）。
6. 敵人死後會掉落薄荷綠方塊（經驗）與珊瑚色方塊（回血），走近自動吸收；經驗滿了就升級，自動回滿血，最大血量與技能傷害小幅提升（不會彈出選單）。
7. 左上角顯示等級、血量、波數與技能冷卻。血量歸零會倒地，按 **R** 重新開始。

如果出現紅色錯誤，請截圖或複製底部的紅字給我。

## 專案結構

| 檔案 | 用途 |
|---|---|
| `project.godot` | Godot 專案設定（放在 repo 根目錄，Godot 才讀得到 `assets/`） |
| `game/main.tscn` | 主場景：地板、Jax、鏡頭、燈 |
| `game/scripts/jax.gd` | Jax 移動、走路動畫、「拆場」技能 |
| `game/scripts/camera_follow.gd` | 鏡頭跟隨 |
| `game/enemy.tscn`、`game/scripts/enemy.gd` | 敵人：追人、近身攻擊、受擊閃白與擊退（40 血） |
| `game/scripts/projectile.gd` | 遠程敵人的飛彈 |
| `game/scripts/speed_lines.gd` | 衝刺與重擊時的放射速度線 |
| `game/scripts/zone.gd` | 地面範圍（預警圈、殘留區） |
| `game/scripts/pickup.gd` | 掉落物（經驗、回血） |
| `game/scripts/main.gd` | 一波波生成敵人 |
| `game/scripts/street.gd` | 用方塊程式生成街道、建築、路燈、樹、車（色票見 `style-guide.md`） |
| `game/scripts/hud.gd` | 左上角血條、波數、技能冷卻 |
| `assets/characters/jax.glb` | Jax 低多邊形模型（由 Blender 腳本生成） |
| `tools/blender/make_jax.py` | 生成 Jax 模型的腳本 |

`.godot/` 是 Godot 自動產生的快取，已被 `.gitignore` 排除。

## 修改 Jax 模型（之後才需要）

模型由腳本生成，要改顏色或尺寸，就修改 `tools/blender/make_jax.py` 再執行；你也可以直接在 Blender 開啟 `assets/characters/jax.glb`（File → Import → glTF）查看。預覽圖：`docs/art/jax-preview.png`。

## 畫面風格設定

專案使用 640×360 低解析度渲染再放大 2 倍（`project.godot` 內的 `display/window/stretch`），所以畫面有像素階梯感，對應參考影片的復古低解析風格。最新畫面預覽：`docs/art/gameplay-preview.png`。

## 卡匣配件（隨機掉落加組合 build）

目前有 2 張卡匣，每張 2 個配件槽：**拆場 Demolish**（Q 或右鍵）與**滑板衝刺 Skate**（Space）。**配件由敵人隨機掉落**（大方塊，顏色代表稀有度：白 Normal、藍 Magic、黃 Rare），走近自動拾取進背包（上限 10 件）。前 2 隻敵人必定掉落一件。

**拆場配件（8 款）**

| 配件 | 效果 |
|---|---|
| 重踏 Heavy Stamp | 傷害提升，蓄力慢 0.2 秒 |
| 迴響震擊 Echo Slam | 連擊（Rare 連 3 下） |
| 焦土 Scorch Zone | 留下持續傷害區 |
| 定時炸彈 Time Bomb | 延遲爆發，範圍更大、傷害更高 |
| 重拳 Gut Punch | 擊飛敵人 |
| 黑洞 Black Hole | 先把敵人吸向中心再爆炸 |
| 連鎖反應 Chain Reaction | 被打中的敵人再爆炸，波及附近 |
| 腎上腺素 Adrenaline | 每擊中一隻敵人就縮短冷卻 |

**衝刺配件（4 款）**

| 配件 | 效果 |
|---|---|
| 火焰軌跡 Flame Trail | 衝刺路上留下火焰區 |
| 磨擦衝撞 Grind Strike | 衝刺穿過敵人並造成傷害 |
| 雙重衝刺 Double Dash | 多衝刺一次 |
| 殘影 Afterimage | 無敵時間加長 |

稀有度越高，效果越強（Magic +15%、Rare +30%），並帶有隨機詞綴：Magic 1 條、Rare 2 條（+傷害%、+範圍、−冷卻%）。

按 **C** 開啟工作枱（遊戲暫停）：
- 點選背包中的配件，按 **Equip／Unequip** 裝上或拆下（自動裝入對應卡匣）；點擊上方的槽可以直接拆走。
- **單據**用途：**Reroll（2）** 重擲詞綴（Magic、Rare）、**Upgrade（3／6）** 提升稀有度（Normal→Magic→Rare，詞綴重新抽取）、**Scrap（+1）** 拆解配件換取 1 單據。
- 配件可以疊加，例如 Echo Slam＋Time Bomb、Flame Trail＋Double Dash。

**語言：** 遊戲內文字暫時全部是中文（字體使用系統字體，Windows 與 Mac 直接顯示；日後出網頁版要另外放入中文字型檔）。

## 普通攻擊

附近 2.2 米內有敵人時，Jax 會**自動揮擊**（9 點傷害、約 0.55 秒一下，只有白色小圈，沒有字卡），走路時也會攻擊。字卡與速度線留給大技：拆場一定會彈出，滑板衝刺要裝了衝刺配件才會彈出。第 2 件掉落必定是衝刺配件。

## 地圖據點與推進

不再有一波波刷怪。街區裡分佈 4 個敵群（據點），一開始全部站定不動，左上角顯示「據點 x/4」：
- 你走近（約 9 米）或打其中一隻，同一據點的敵人會一起追上來。
- 由近至遠，後面據點的敵人更強、遠程更多。
- 街區北面（畫面遠方）是頭目，走近才會醒來。

## 死亡與成長

死亡後按 **R** 重新開始：**等級、背包、已裝備的配件都保留**，單據損失一半，敵群與頭目全部重置，從起點再推進。通關後按 R 也會保留。這個保留只在遊戲開啟期間有效，關機再開要等之後加入存檔。

## 頭目與通關

頭目「收數大佬」（畫面底部有血條）：
- 追著你近身攻擊（12 點傷害）。
- 每隔幾秒朝你所在的位置**預警重擊**：地面先出現黃圈，1 秒後爆開（22 點傷害），要及時衝刺躲開。
- 血量剩一半時召喚 3 隻小弟。
- 被打敗後掉落 3 件配件與 10 單據，畫面顯示「通關！」，按 **R** 再玩一次。

## 打擊演出

- **技能字卡：** 施放「拆場」或衝刺時，畫面中間彈出橫幅字卡（DEMOLISH／SKATE DASH），拆場字卡下面會列出已裝備的配件名。
- **速度線：** 衝刺與重擊命中敵人時，畫面射出放射狀白色速度線（命中越多越強）。
- 另外有頓幀與鏡頭震動。

## 第一章（故事流程）

遊戲現在從選角開始，走完第一章（詳細設定見 `docs/design/chapter-1-story.md`）。

- **選角：** 按 1 至 4 選角色，目前只有 Jax 可玩。
- **互動：** 走近發光提示出現時按 **E**（拍電視、開冰箱、買東西、接設備等）。
- **流程：** 合租單位（拍電視、冰箱、字條、工具架、工作枱、衝過電線、推開雜物）→ 街道（Bo 商店、黑西裝人上門、雜貨店首戰、掉落核准模組）→ 向當舖老闆打聽 → 後巷維修場（通行零件、裝甲敵人）→ 天台（借天線）→ 管理站（頭目 TK-075「收據」）→ 回家拿頭盔 → 衝出封鎖線與高架橋追逐（只演出）→ 運輸平台（頭目 TK-060「領帶」）→ 回家吃三明治。
- **裝甲敵人：** 普通攻擊幾乎無效，用拆場（Q／右鍵）才能破防。
- **自由練習：** 街道北端左邊的入口通往舊試玩場（4 個據點加頭目）。
- 死亡後按 R 重開所在場景；等級、配件、劇情進度保留（關機後不保留，存檔之後再做）。
- 結局後按 R 重新開始第一章。
