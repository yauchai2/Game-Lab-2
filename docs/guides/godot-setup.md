# 開啟 Jax 試玩版（Godot）

專案已經建好，你**唔需要自己砌場景**，只要安裝 Godot 同打開。

## 1. 安裝 Godot

1. 去 https://godotengine.org/download ，下載 **Godot 4.4 或以上嘅標準版（Standard，唔係 .NET）**。
2. 解壓縮 zip，入面一個 `.exe`，**唔使安裝**，雙擊就開。放喺 repo 以外（例如 `C:\Godot\`）。

## 2. 取得專案

用 Git 或 GitHub Desktop 將 `Game-Lab-2` repo 下載到電腦（切換到 PR #1 嘅 branch `claude/project-thread-0f5oar`，合併後用 `main`）。

## 3. 打開同玩

1. Godot 啟動後按 **Import**，選 repo 根目錄的 `project.godot`，按 **Import & Edit**。（第一次會自動匯入模型與音效，需要等一會。）
2. 按右上角 **▶**（`F5`）。標題畫面選「新遊戲」（再選 Jax 或 Skye）或「繼續」（讀取存檔）。
3. **WASD**（或方向鍵）移動：W 往畫面上方、S 往下、A 往左、D 往右（鏡頭是固定的 45 度斜向等距俯視，所以街道在畫面上是斜的）。**滑鼠滾輪**縮放鏡頭；移動時鏡頭會稍微領前，頭目戰會自動拉遠。
4. 敵人分佈在街區的 4 個據點，走近才會一起追上來；北面盡頭是頭目。**Q** 或滑鼠**右鍵**放大技（Jax 拆場、Skye 惡作劇彈）。普通攻擊由武器決定，自動出手。
5. **空白鍵**衝刺（有按方向鍵就朝該方向，否則朝滑鼠位置；衝刺期間無敵，冷卻 1 秒）。
6. 敵人死後掉經驗、回血、單據與配件／裝備，走近自動撿取。背包滿了，物品會留在原地，到工作枱（**C**）拆解後再撿。
7. 左上角顯示等級、血量、據點進度；畫面底部是技能列與冷卻。血量歸零會倒地，按 **R** 重新開始（保留等級與裝備）。**M** 開關音樂。

如果有紅色錯誤，截圖或複製底部紅字給我。

## 修改 Jax 模型（之後先需要）

模型用腳本生成，改顏色或尺寸就改 `tools/blender/make_jax.py` 再執行；你亦可以直接喺 Blender 打開 `assets/characters/jax.glb`（File → Import → glTF）睇。預覽圖：`docs/art/jax-preview.png`。


## 畫面風格設定

專案用 640×360 低解析度渲染再放大 2 倍（`project.godot` 內 `display/window/stretch`），所以畫面有像素階梯感，對應參考影片嘅復古低解析風格。最新畫面預覽：`docs/art/gameplay-preview.png`。

## 卡匣配件（隨機掉落 + 砌 build）

現時有 2 張卡匣，每張 2 個配件槽：**拆場 Demolish**（Q／右鍵）同 **滑板衝刺 Skate**（Space）。**配件係敵人隨機掉落**（大方塊，顏色代表稀有度：白 Normal、藍 Magic、黃 Rare），行近自動拾取入背包（上限 10 件）。頭 2 隻敵人必掉一件。

**拆場配件（8 款）**

| 配件 | 效果 |
|---|---|
| 重踏 Heavy Stamp | 傷害提升，蓄力慢 0.2 秒 |
| 迴響震擊 Echo Slam | 連擊（Rare 連 3 下） |
| 焦土 Scorch Zone | 留下持續傷害區 |
| 定時炸彈 Time Bomb | 延遲爆發，範圍更闊、傷害更高 |
| 重拳 Gut Punch | 擊飛敵人 |
| 黑洞 Black Hole | 先將敵人吸向中心再爆 |
| 連鎖反應 Chain Reaction | 被打中嘅敵人再爆炸，波及附近 |
| 腎上腺素 Adrenaline | 每擊中一隻敵人縮短冷卻 |

**衝刺配件（4 款）**

| 配件 | 效果 |
|---|---|
| 火焰軌跡 Flame Trail | 衝刺路上留下火焰區 |
| 磨擦衝撞 Grind Strike | 衝刺穿過敵人造成傷害 |
| 雙重衝刺 Double Dash | 多衝一次 |
| 殘影 Afterimage | 無敵時間加長 |

稀有度愈高，效果愈強（Magic +15%、Rare +30%），而且帶隨機詞綴：Magic 1 條、Rare 2 條（+傷害%、+範圍、-冷卻%）。

按 **C** 打開工作枱（遊戲暫停）：
- 點背包配件選取，按 **Equip／Unequip** 裝上或拆下（自動裝入對應卡匣）；點上面嘅槽可以直接拆走。
- **單據**用途：**Reroll（2）** 重擲詞綴（Magic／Rare）、**Upgrade（3／6）** 升稀有度（Normal→Magic→Rare，詞綴重新抽）、**Scrap（+1）** 拆解配件換 1 單據。
- 配件可以疊加，例如 Echo Slam + Time Bomb、Flame Trail + Double Dash。

**語言：** 遊戲內文字暫時全部係中文（字體用系統字體，Windows／Mac 直接顯示；日後出 Web 版要另外放中文字型檔）。

## 選角與兩個角色

遊戲一開始是選角畫面（Jax／Skye，點「選擇」進入）。兩人共用同一套卡匣配件系統，但玩法不同：

| | Jax 傑克斯 | Skye 絲凱 |
|---|---|---|
| 定位 | 近身重擊 | 遠程惡作劇 |
| 生命／速度 | 120／6.0 | 90／6.4 |
| 起始武器 | 鐵管（近戰） | 手槍（遠程） |
| 大技（Q／右鍵） | 拆場：在身邊爆開 | 惡作劇彈：投向滑鼠位置（最遠 9 米）爆開 |
| 衝刺（空白鍵） | 滑板衝刺 | 同一個衝刺 |

配件對兩人都有效（例如黑洞會把敵人吸向落點）。死亡後按 R 會保留同一角色。Skye 的模型由 `tools/blender/make_skye.py` 生成，預覽在 `docs/art/skye-preview.png`；目前她的槍械輪替、舞步等特色還沒做，只是最小可玩版本。

## 裝備系統（任何角色都能穿任何裝備）

除了卡匣配件，還有 5 個裝備欄：**武器、頭部、身體、腳部、飾物**。裝備一樣是敵人隨機掉落，有稀有度（普通／魔法／稀有）與隨機詞綴；**角色不限制裝備**，Jax 可以拿槍、Skye 可以拿鐵管，用來砌出不同的搭配。

- **武器決定普通攻擊**（自動出手，沒有字卡）：

| 武器 | 類型 | 傷害 | 間隔 | 射程 |
|---|---|---|---|---|
| 鐵管 | 近戰 | 10 | 0.55 秒 | 2.2 米 |
| 拳套 | 近戰 | 6 | 0.32 秒 | 1.8 米 |
| 手槍 | 遠程 | 7 | 0.40 秒 | 9 米 |
| 步槍 | 遠程 | 13 | 0.75 秒 | 11 米 |
| 散彈槍 | 遠程（同時打最近 3 個） | 6×3 | 0.90 秒 | 6 米 |

  沒有武器時是空手（近戰，傷害 5）。起始武器：Jax 鐵管、Skye 手槍，之後可隨意換。
- **其他裝備**提供基礎屬性：冷帽（生命）、護目鏡（普攻速度）、工裝外套（生命）、帆布背心（技能傷害）、厚底板鞋（移速）、彈跳鞋（技能冷卻）、粗鎖鏈（技能傷害）、懷錶（技能冷卻）、幸運符（普攻傷害）。詞綴可再加生命、移速、普攻傷害、普攻速度、技能傷害、技能冷卻、射程。
- 普攻傷害另外隨等級成長（每級 +4%）；「技能傷害／技能冷卻」對拆場、惡作劇彈與衝刺都有效。

**裝備頁（C）** 參考 PoE 2：左邊是物品提示框（名稱按稀有度上色、類型、武器數值、藍色詞綴、裝上後會替換什麼）與目前屬性；右邊上方是人形裝備欄（武器在左、頭／身／腳在中、飾物在右）與兩張技能卡匣的配件槽，下方是 12 格背包（邊框顏色代表稀有度，已裝備的標「已裝」）。

- 滑鼠移到任何物品或欄位上，即時顯示提示框。
- 單擊選取，**雙擊直接裝上／拆下**；也可用下方按鈕：裝上／拆下、重擲（2 單據）、升級（3／6）、拆解（+1）。單據不足時按鈕變灰。
- 背包滿了，物品會留在原地，拆解後再撿。

**掉落物名牌**（仿 PoE 2）：敵人掉落的配件與裝備在地上顯示為深色名牌，文字按稀有度上色（白／藍／黃），多件會疊排，另有一根光柱方便找；走近自動撿取。背包滿了名牌會變暗。

遊戲中畫面底部有技能列：拆場（Q）、衝刺（空白）、武器，各自顯示已裝配件與冷卻。

## 普通攻擊

由目前武器決定（見上表）：近戰武器在身邊範圍揮擊（白色圈），遠程武器自動射擊射程內最近的敵人（黃色彈道）。字卡與速度線只留給大技與裝了衝刺配件的衝刺。

## 第一章流程（橋底街）

1. **開場字幕**：三張字卡，按 **E**／空白／滑鼠左鍵繼續。
2. **與 Bo 交談**：起點旁邊的黃色人物是 Bo，走近按 **E**。畫面上方一直顯示目前目標。
3. **清理據點**：4 個據點的失控設備；教學提示（移動、大技、衝刺、工作枱）會在需要時出現，用過就消失。
4. **頭目「收據」（TK-075）**：北面盡頭。醒來時有一句對白；追擊、預警重擊（地面黃圈，1 秒後爆開，22 傷害）、血量一半時召喚 3 隻小弟。擊敗後掉 3 件配件與 10 單據。
5. **回商店結算**：回到 Bo 那裡按 **E**，二選一：「照單交還，整件回收」（單據 +6）或「留下店家在用的貨」（單據 +3，Bo 保住工作枱）。之後有 Ada 一句話帶出下一章。
6. **章節完結畫面**：選「再玩一次（保留成長）」或「回標題」。

**存檔**：每清完一個據點、擊敗頭目、倒下與通關時，等級、背包、配件、單據與章節進度會寫入存檔（`user://save.dat`），標題畫面按「繼續」讀取。倒下後按 **R** 重新開始，保留成長但單據減半。

## 技能列（Q／E／R／F）

| 鍵 | 技能 | 解鎖 | 說明 |
|---|---|---|---|
| Q／右鍵 | 角色招牌技（拆場／惡作劇彈） | 開局 | 見上表 |
| E | 鐵鍊旋風 | 等級 2 | 身邊連續三下範圍打擊，冷卻 4 秒 |
| R | 衝擊線 | 等級 3 | 朝滑鼠方向炸出一排四個爆炸，冷卻 5 秒 |
| F | 油門全開 | 等級 4 | 5 秒內移速 +40%、普攻速度 +30%，冷卻 14 秒 |
| 空白鍵 | 衝刺 | 開局 | 見上表 |

每個技能有自己的 2 個配件槽。在工作枱點選技能槽（左下技能區），再裝上配件，配件就會裝進該技能；沒有指定時裝進第一個有空槽的已解鎖技能。配件只影響裝了它的那個技能（例如重踏裝在 R，Q 不會變慢）。油門全開只有「冷卻」與「範圍」詞綴有效（範圍延長持續時間）。

## 防禦：護甲與抗性

- **護甲**減少物理傷害（近戰敵人、頭目的攻擊）：減傷 = 護甲／（護甲＋10×該次傷害），上限 80%。傷害愈大，護甲愈沒用，所以對頭目重擊要靠別的辦法（閃避）。
- **抗性**減少元素傷害，分火焰、冰凍、閃電三種，上限 75%。遠程敵人的彈丸是元素傷害：第 2 個據點用火（橙）、第 3 個冰（藍）、第 4 個閃電（黃）。
- 裝備基礎屬性與詞綴都可能帶護甲或抗性（冷帽、工裝外套、帆布背心、粗鎖鏈有護甲；厚底板鞋冰抗、懷錶火抗、幸運符電抗）。工作枱左下角的屬性欄會列出目前護甲與三種抗性。
- 你受到的傷害數字按元素上色。

## 補給（汽水與便當）

按 **1** 喝汽水（立刻回復 45% 生命，最多 3 格）、按 **2** 吃便當（6 秒內回復 40% 生命，最多 2 格）。補給靠擊殺回充：汽水每 4 隻、便當每 6 隻回充 1 格。畫面右下角顯示剩餘格數；血滿時不會浪費。

## 戰鬥讀感（傷害數字、血條、破防）

- 命中時敵人頭上飄出白色傷害數字，你受傷時是紅色數字；敵人受傷後頭上才出現血條。
- 左下角是生命球（紅球，依血量比例填滿）。
- 頭目血條下方有**破防條**：持續命中會累積，滿了頭目暈眩 3.5 秒（閃藍光、取消預警重擊），期間受到的傷害 +30%，是爆發的好時機；一段時間不打會慢慢退回。
- 掉落名牌：**Z** 切換「隱藏白色名牌」，按住 **Alt** 暫時顯示全部；**點名牌**可以把該物品吸過來撿取。
